# Урок 01. Из Figma в React

Учебный проект: Primary и Secondary, размеры S/M/L, настоящие hover/active/focus/disabled.
Это первый фрагмент дизайн-системы, а не полный экспорт Figma.

## Запуск на этом Mac

Из терминала VS Code в папке проекта:

```sh
./start.command
```

Открой адрес, который появится в терминале. Остановить сервер: Ctrl+C.
Локальная Node.js находится в соседней `.tools`; запуск не требует глобальной установки.
На другом компьютере установи Node.js 22.12+ и выполни `npm ci`, затем `npm run dev`.

## Как читать проект

1. `src/components/Button.tsx` — компонент: какие свойства он принимает и какую кнопку создаёт.
2. `src/components/button.css` — оформление и состояния компонента.
3. `src/tokens.css` — статические и семантические переменные.
4. `src/App.tsx` — страница, где создаются экземпляры Button.

## Твоё первое изменение

В `src/tokens.css` поменяй `--purple-600: #673ab7` на другой цвет и сохрани файл.
Браузер обновит кнопку Primary. Верни исходное значение через Undo.
Затем в `src/App.tsx` найди `useState('Продолжить')` и поменяй начальный текст.

## Важные соответствия

В Figma Type соответствует `variant`, Size — `size`, надпись — `children`.
Тип HTML-кнопки называется `type`, поэтому для вида используем другое имя — `variant`.
Hover/active обрабатывает CSS, а `disabled` — нативное свойство HTML.
Фокус виден при управлении клавиатурой. Нажатия Enter и Space поддерживаются браузером.

## Шрифты

Подключены имеющиеся RF Dewi Regular (400) и Bold (700).
Токен кнопки 600 сохранён из Figma, но отдельного файла Semibold нет:
браузер выберет ближайшее доступное начертание. Для точного соответствия
нужно добавить лицензированный RF Dewi Semibold и объявить @font-face с весом 600.
Не публикуй файлы шрифта без проверки условий своей лицензии.
